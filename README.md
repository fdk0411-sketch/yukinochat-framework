# YukinoChat Framework 0.1.0-rc.1

Windows 本地 AI 对话手记框架测试版。支持流式文字、会话切换、停止回复、JSON 导出与本地保存。
本版采用中性背景与独立助理提示词；不包含雪乃美术、Live2D 模型/运行库、语音音色或小说材料。
原项目的角色控制与语音接口源码作为开发参考保留，界面中不启用这两项功能。

## 安装与启动

1. 安装 [Node.js 24 LTS](https://nodejs.org/)，通过 [Codex 官方仓库说明](https://github.com/openai/codex) 安装 Codex CLI，并使用自己的账户完成登录。
2. 下载本版本 ZIP，完整解压至你有写入权限的普通文件夹。不要直接在 ZIP 内运行。
3. 双击 `Check.cmd` 检查环境，再双击 `Start.cmd`。首次运行会创建缺失的配置，不覆盖已有配置。
4. 浏览器打开后，等待连接状态就绪，再发送消息。推理服务需要网络和账号可用额度；本包不包含账号或免费模型服务。
5. 结束使用时运行 `Stop.cmd`。只关闭浏览器会保留后台服务。

这是需要上述依赖的便携源码包，不是已经捆绑全部运行环境的一键离线安装器。
CLI：`node scripts/initialize.mjs`，然后 `npm start`。直接 `npm start` 前必须初始化配置。
开发测试：`npm test`。应用运行只使用 Node 内置模块，无需 `npm install` 下载应用依赖。

## 数据、权限与更新

只监听本机 127.0.0.1；默认端口 8821，占用时启动器尝试后续端口。
聊天存于 `data/`，日志存于 `logs/`，专用浏览器档案存于 `data/browser-profile/`。
代码通过官方 Codex app-server 使用用户自己的登录，不把账号交给其他用户。
对话默认 read-only 沙箱和 on-request 审批；未经你确认的操作不能由页面伪造批准。
发送的文本会交给你使用的模型服务；“本地窗口”不等于离线推理或不向模型服务传输消息。
本版不发送语音请求、不自动启动语音模型。人设位于 `persona/assistant.md`，不读取电脑上的角色 skill。

升级前先停止服务、备份旧目录；将旧 `data/` 和自己的 `reply/config.json`、`voice/config.json` 复制到新版本对应目录后启动。
本版尚无自动升级、安装器卸载或签名。卸载前停止服务并自行保留需要的聊天记录。
不要上传自己的 data、日志、浏览器档案、凭据或私有素材。

## 排错

- 启动失败：先运行 Check.cmd，再查看 logs/launcher.log；确认 Node 和 Codex 安装可用。
- 页面显示未登录：完成自己的官方 Codex 登录，停止并重新启动。
- 公司设备阻止脚本/程序：遵循设备管理规则，请管理员协助，不修改系统安全策略。
- 页面加载成功不等于模型回复成功；账户、网络和可用模型均需满足条件。
